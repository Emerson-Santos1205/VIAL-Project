# Theory of Distributed Organizational Cognition (TDOC)

## Purpose

The TDOC defines the theoretical foundation of the VIAL Platform.

It describes the universal principles governing Distributed Cognitive Organizations independently of implementation technologies.

TDOC is the highest theoretical authority of the VIAL ecosystem.

---

# Scope

The TDOC defines:

- Organizational Cognition
- Organizational Cognitive State
- Organizations
- Goals
- Roles
- Capabilities
- Policies
- Decisions
- Evidence
- Organizational Evolution
- Cognitive Coordination

The TDOC does not define:

- APIs
- Protocols
- SDKs
- Runtimes
- Databases
- Programming Languages
- AI Models

These belong to lower specification levels.
